## Open-Source GitHub Projects



- **[OPC-Agents](https://pypi.org/project/opc-agents/)**  

  Open-source AI execution team for one-person companies. Tell it what you need and it delivers finished artifacts — research reports with source links, marketing plans with SMART goals and roadmaps, competitor SWOT analyses, emails sent via SMTP with rate limiting, financial records with monthly reports, and client profiles with encrypted storage. Features **Three Sages Parallel Voting Architecture** (StrategistBrain, ExecutorBrain, ReflectorBrain) with pre-decision consensus protection, IntentRouter three-way intelligent routing (SIMPLE/COMPLEX/GREETING), and i18n refactored to 133 lines of logic. MIT licensed .



- **[gMAS (frontier-ai-gmas)](https://pypi.org/project/frontier-ai-gmas/)**  

  Open-source multi-agent coordination platform with **RoleGraph** dynamic topology, runtime adaptation hooks (stop, skip, force agents; add/remove edges), and blocking/async/streaming execution modes. Features per-agent model caller assignment (hosted APIs, OpenAI-compatible gateways, or local models), ToolRegistry with shell/code/web search/browser/MCP/computer use tools, budget management (token/time budgets, timeouts, retries), and comprehensive observability (final answer, execution order, per-agent messages, token totals, errors, fallbacks, pruned agents, hidden states, early-stop details). PyTorch Geometric export for graph learning experiments .



### Additional Strong Open-Source Options



- **Cline** — Open-source autonomous coding agent with 62K+ stars, 46 providers, human-in-the-loop approval, and mature MCP integration.

- **Aider** — Terminal-based AI pair programming with git integration and auto-commit. 30K+ stars.

- **OpenHands** — Platform for building and running AI coding agents with sandboxed execution. 68K+ stars. 77.6% on SWE-Bench.

- **Goose** — Rust-based general-purpose AI agent from Block under Linux Foundation. 48K+ stars. Desktop, CLI, and API with 70+ MCP extensions.

- **TPT Anvil** — Privacy-first Copilot alternative with local LLM inference (llama.cpp, Ollama), GPU acceleration, and 100% local default with zero telemetry.



**Frameworks for building custom systems**: Combine **OPC-Agents** for one-person business task execution, **gMAS** for multi-agent coordination with dynamic topology, **Cline** or **Aider** for coding assistance, **Goose** for general-purpose agent workflows, and **Ollama** for local LLM inference to build a complete self-hosted virtual AI colleague stack.
